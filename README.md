# Task Flow

Менеджер личных задач с таймером обратного отсчёта на Next.js. Практическое задание «CRUD + состояние, таймер + интерфейс».

## Возможности

- **Создание.** Форма принимает название, минуты и секунды. Пустая задача не добавляется, время не может быть отрицательным, секунд — больше 59. Есть быстрый выбор: 5 / 15 / 25 / 45 минут.
- **Управление.** Переименование (кнопка-карандаш или двойной клик; Enter — сохранить, Esc — отменить), отметка выполненной, удаление. Выполненная задача останавливает таймер, её название зачёркивается.
- **Таймер.** У каждой активной задачи свой запуск, пауза и сброс, время в формате MM:SS. Когда время выходит, звучит короткий сигнал и задача подсвечивается.
- **Навигация.** Фильтры «Все», «Активные», «Выполненные», счётчик активных задач, «Удалить выполненные». Сверху — сводка за день: активные, выполненные, общий остаток времени.
- **Данные.** Задачи сохраняются в `localStorage`. После перезагрузки задачи, статусы и оставшееся время на месте. Запущенный таймер хранит момент окончания, поэтому продолжает идти и после перезагрузки страницы. Вкладки синхронизируются между собой.
- **Адаптивность.** Вёрстка для телефона, планшета и десктопа, светлая и тёмная тема по настройкам системы.

## Стек

- Next.js 16 (App Router), React 19, TypeScript
- date-fns — дата в шапке
- CSS Modules, без UI-библиотек
- Внешнего бэкенда нет

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build`, проверка кода: `npm run lint`.

## Страницы

- `/` — рабочая область со списком задач
- `/about` — описание приложения и автора (данные автора — в `src/data/about.ts`)

## Структура

```
src/
  app/                 layout, главная, /about, иконка
  components/
    layout/            шапка, навигация, футер
    tasks/             доска задач: форма, список, карточка, таймер, фильтры, футер списка
    ui/                иконки, кнопка-иконка
  data/                контент страницы /about
  hooks/useTasks.ts    подписка на хранилище через useSyncExternalStore
  lib/
    tasks-store.ts     хранилище задач, таймеры, localStorage
    validation.ts      проверка формы
    time.ts            формат MM:SS, статусы задачи
  types/task.ts        тип задачи
```

Серверные компоненты — страницы, шапка и футер. Всё интерактивное (доска задач, навигация с активной ссылкой) — клиентские компоненты.
